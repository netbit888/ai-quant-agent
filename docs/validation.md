# 回测引擎验证记录

> 目的：明确 Python 引擎（`backtest/`）哪些结论可信、哪些存疑。
> 任何基于本引擎的收益结论，必须先看过这份文档。

## 一、基准数据来源

MT5 策略测试器导出的原始报告：
`data/reports/ReportTester-<login>.html`

| 项 | 值 |
|---|---|
| EA | ExpertMACD（官方示例，MACD 12/24/9，TP 50 / SL 20 points） |
| 品种 | XAUUSDm |
| 周期 | H1 |
| 区间 | 2025.01.01 - 2025.12.31 |
| 初始入金 | 10000 USD |
| 手数 | 0.1 |
| 模型 | 1 分钟 OHLC（报告 `柱 5889 / 报价 23389`，报价 ≈ 4×柱，确认为 M1 模型） |

MT5 结果：净盈利 136.32｜交易 1136 笔｜胜率 45.86%｜盈利因子 2.10｜最大回撤 39.43（0.39%）｜平均盈利 0.50｜平均亏损 -0.20

## 二、已验证（有证据支撑）

| 项目 | 证据 | 置信度 |
|---|---|---|
| 点值换算 | 0.1 手黄金，每 point = 0.01 USD；TP 50 points = 0.50，SL 20 points = -0.20 | 高 |
| TP/SL 触发逻辑 | Python 引擎 avg_win = 0.50、avg_loss = -0.20，与 MT5 **完全一致** | 高 |
| 手数/合约价值 | 同上 | 高 |
| 信号计算 | MACD 交叉方向一致（净盈利符号一致） | 中高 |

**关键结论：金额模型和 TP/SL 触发是对的。** 这是回测引擎最核心的部分。

## 三、未验证（存疑，不能拿来做决策）

| 项目 | 为什么存疑 | 影响 |
|---|---|---|
| 多笔连续持仓 | 当前引擎一次只持一仓，MT5 的 CExpert 可能允许挂单/部分成交 | 交易数偏差 |
| 点差在开平仓两侧的分配 | 引擎在平仓时一次性扣往返点差，MT5 是 ask/bid 分离 | 高频策略误差放大 |
| 跳空/极端行情 | 引擎按 bar 路径模拟，跳空时成交价假定为路径价 | 大波动时低估风险 |
| 滑点 | 完全未建模 | 实际收益低于回测 |
| 手续费/隔夜利息 | 未建模 | 长持仓策略高估收益 |
| 部分成交/拒单 | 未建模 | 极端行情不可复现 |

## 四、已知差异及原因

| 指标 | Python | MT5 | 差异原因 |
|---|---|---|---|
| 交易数 | 463 | 1136 | **粒度不同**：MT5 用 M1（每 H1 bar 拆 4 个价格点），SL/TP 更快触发、更快再入场；Python 用 H1 bar 路径 |
| 胜率 | 52.05% | 45.86% | 同上，M1 粒度下止损触发更早更频繁 |
| 净盈利 | 76.10 | 136.32 | 同上 |

**判定**：差异来自成交粒度，不是逻辑错误。金额模型一致（avg_win/avg_loss 完全相同）是强证据。

## 五、成本敏感性（这次校准最有价值的发现）

同一策略、同一区间，只改点差：

| 点差 (points) | 净盈利 | 胜率 | 说明 |
|---|---|---|---|
| 0 | +76.10 | 52.05% | MT5 测试器“当前点差”接近此档 |
| 20 | -16.50 | 52.05% | 0.02 美元/盎司即转亏 |
| 240 | -1035.10 | 0% | **黄金真实点差** |

**结论：TP 50 points 的策略在黄金真实点差下必亏。** 本项目所有策略的 TP 必须 > 360 points（点差 1.5 倍），这条已写入 prompt 硬约束和 `validate_constraints`。

## 六、补验计划（阶段 3 之前必须完成）

1. 把 Python 策略翻译成 MQL5，在 MT5 用**仅开盘价**模型跑同区间
2. 对比交易数与净盈利，差异应 < 15%
3. 若差异 > 50%，逐笔比对前 10 笔交易，定位成交模型 bug

**在此之前，任何“策略有效”的结论都只能算内部一致性，不能算外部验证。**

## 七、数据完整性事故（2026-10-19 发现并修复）

### 问题

`data/XAUUSDm_H4.csv` 共 16503 根，但逐年检查中位 bar 间隔发现：

| 年份 | bars | 中位间隔 |
|---|---|---|
| 2014 | 302 | **24.0h** |
| 2015 | 312 | **24.0h** |
| 2016 | 310 | **24.0h** |
| 2017 | 1364 | 4.0h |
| 2018-2026 | 1274~1654 | 4.0h |

**2014-01 ~ 2016-12 实际是日线级数据**（券商历史库存只到日线精度），2017-01 起才是真正的 H4。

### 影响

Gate 2 的第一项判定是「盈利年份占比 ≥ 70%」。分母里混进了 3 个日线年份，
它们贡献的 5/3/4 笔交易与 H4 交易完全不可比。之前的「Gate 2 首次通过」
有一部分是靠这三年撑起来的，属于无效结论。

### 修复

新增 `backtest/dataquality.py`：

- `scan_segments()`：按年报出根数与中位间隔，暴露粒度漂移
- `trim_to_timeframe()`：切掉与目标周期粒度不符的**头尾段**（中间漂移不切，
  因为那说明数据本身坏了，应当拒绝使用并告警）
- `aqa.read_bars()` 默认启用，所有命令自动受保护

实测剔除结果：

| 文件 | 原始 | 保留 | 区间 |
|---|---|---|---|
| XAUUSDm_H4 | 16503 | **15579** | 2017-01-03 ~ 2026-10-19 |
| EURUSDm_H4 | 9432 | 8654 | 2021-01-03 ~ 2026-10-19 |
| GBPUSDm_H4 | 9470 | 8692 | 2021-01-03 ~ 2026-10-19 |
| US30_x10m_H4 | 2155 | 2155 | 2025-06-15 ~ 2026-10-19 |
| XAUUSDm_H1 | 50000 | 50000 | 2018-05-10 ~ 2026-10-19 |

顺带暴露：**EURUSD/GBPUSD 的 H4 只有 2021 年起，US30 只有 2025-06 起。**
此前「三品种组合把回撤从 32% 压到 15%」的结论里，非黄金品种的贡献被高估了
（历史长度差 4 年以上，合并时前向填充让黄金主导了前期权益）。

## 八、参数稳健性扫描（2026-10-19）

工具：`python -m tools.sweep`（或 `aqa.py sweep`）
训练段 2017-2023（11100 根）／测试段 2024-2026（4479 根），资金 3000，风险 2%，点差 180。

### 8.1 网格结果

120 组（`max_atr_ratio` × `min_structure_points` × `rr_target`）：

| 指标 | 值 |
|---|---|
| 训练段达标（PF≥1.2 且盈利） | 98/120 |
| 其中测试段仍达标 | 68/98 = **69%** |
| 全网格双绿比例 | **57%** |

### 8.2 训练段最优 = 样本外崩塌

| 参数 | 训练净利 | 训练 PF | 测试净利 | 测试 PF |
|---|---|---|---|---|
| atr3.0 / struct0 / **rr3.0** | **3801**（第 1 名） | 1.48 | **133** | **1.05** |
| atr0 / struct0 / rr3.0 | 3800 | 1.48 | 92 | 1.03 |
| atr2.5 / struct14000 / rr2.0 | 1962 | 2.04 | 1113 | 1.56 |

**训练段最赚的 5 组参数全部是 `struct=0 / rr=3.0`，测试段 PF 全部掉到 1.01~1.05。**
这是教科书级的数据窥探反例：按「哪个最赚」选参，样本外直接归零。
机制解释：rr=3.0 在 2017-2023 的低波动慢牛里能吃到长趋势，
2024 后黄金日内波动放大，3 倍目标几乎打不到，信号被反复止损消耗。

### 8.3 单参数敏感性

固定其余两维，一次只动一维：

**`rr_target`（struct=14000, atr=0）**

| rr | 训练净利 / PF | 测试净利 / PF |
|---|---|---|
| 1.5 | 974 / 1.65 | 925 / 1.53 |
| **2.0** | **1685 / 2.01** | **928 / 1.52** |
| 2.5 | 983 / 1.55 | 384 / 1.21 |
| 3.0 | 630 / 1.36 | 355 / 1.18 |

→ rr ≥ 2.5 在样本外系统性塌陷，**2.0 是机制性的最优，不是拟合出来的**。

**`max_atr_ratio`（struct=14000, rr=2.0）**

| atr | 训练净利 / PF | 测试净利 / PF |
|---|---|---|
| 0（关闭） | 1678 / 2.00 | 886 / 1.48 |
| 1.5 | 1193 / 1.87 | 648 / 1.39 |
| **2.0** | 1516 / 1.94 | **421 / 1.24** ← 凹陷 |
| 2.5 | 1685 / 2.01 | 928 / 1.52 |
| 3.0 | 1679 / 2.00 | 928 / 1.52 |
| 4.0 | 1678 / 2.00 | 928 / 1.52 |

→ **这个参数基本无效**（0 和 4 的结果差 2%），而且 2.0 处有个洞。
之前「`max_atr_ratio=2.5` 是避开 2025-2026 亏损的关键」的结论，
是在混有日线的数据上得出的，**在干净数据上不成立**。已默认关闭以去掉一个自由度。

**`min_structure_points` 细扫（rr=2.0, atr=0）**

| struct | 训练净利 / PF / 笔数 | 测试净利 / PF / 笔数 |
|---|---|---|
| 0 | 2590 / 1.36 / 211 | 1063 / 1.31 / 107 |
| 4000 | 529 / 1.13 / 139 | 1045 / 1.33 / 94 |
| 6000 | 862 / 1.23 / 120 | 1051 / 1.36 / 87 |
| 8000 | 711 / 1.22 / 97 | **1243 / 1.48 / 80** |
| 10000 | 910 / 1.32 / 84 | 1082 / 1.47 / 70 |
| 12000 | 1663 / 1.69 / 71 | 1101 / 1.55 / 63 |
| **14000** | **1962 / 2.04 / 60** | **1113 / 1.56 / 62** |
| 15000 | 1678 / 2.00 / 55 | 886 / 1.48 / 58 |
| 16000 | 1792 / 2.14 / 53 | **406 / 1.24 / 53** ← 断崖 |
| 20000 | 795 / 1.65 / 39 | 244 / 1.17 / 44 |
| 25000 | 362 / 1.53 / 23 | 648 / 1.57 / 40 |
| 40000 | 15 / 1.04 / 11 | 584 / 1.69 / 28 |

→ 稳定平台是 **0~14000**（测试 1045~1243），15000 以上进入小样本噪声区。
15000→16000 只少 5 笔却少赚 480 美元，说明该区间完全由个别交易支配。

### 8.4 结论与选参

按「**只用训练段选参，测试段只用来验证**」的纪律：

- `min_structure_points`: 15000 → **14000**（训练段最优，测试段仍 1.56）
- `max_atr_ratio`: → **0（关闭）**，无效果且引入一个假凹陷
- `rr_target`: 保持 **2.0**

改后全区间（2017-2026，点差 180，风险 2%，资金 3000）：

| 指标 | 旧参数 (15000) | 新参数 (14000) |
|---|---|---|
| 总净利 | 2219 | **2824** |
| 盈利年份 | 8/10 | **9/10** |
| 平均 PF | 1.45 | 1.56 |
| 最大回撤 | 15.0% | 15.2% |
| 点差 600 净利 | 1789 | **2636** |

**仍未解决的弱点**：2025 全年只有 +60（PF 1.08，25 笔，胜率 36%，回撤 12.6%），
是全区间最差的一年。2024 后黄金波动结构改变，rr=2.0 的目标变得难打。
这不是调参能解决的，需要机制性改造（移动止损 / 分批止盈 / 波动率自适应目标）。

## 九、机制性改造尝试（两个假设均被证伪）

### 9.1 保本 + 追踪止损 —— 有效但亏钱

引擎新增 `be_at_r` / `trail_start_r` / `trail_gap_r`（默认全关，关闭时与旧版逐分一致）。
R = |开仓价 − 初始止损|。训练段 2017-2023，测试段 2024-2026：

| 设置 | 训练净利 / PF / 胜率 | 测试净利 / PF / 胜率 / 回撤 |
|---|---|---|
| 基线（不用） | 1962 / 2.04 / 50.0% | **1113 / 1.56 / 41.9% / 12.8%** |
| 保本 @1R | 1215 / 1.79 / 40.7% | 901 / 1.48 / 35.9% / 11.4% |
| 追踪 @0.8R/0.8R | 1022 / 1.96 / **73.4%** | 886 / 1.46 / **54.8%** / 8.9% |
| 追踪 @1R/1R | 1077 / 1.85 / 63.9% | 858 / 1.45 / 52.9% / 9.2% |
| 追踪 @1.5R/1R | 1186 / 1.69 / 52.5% | 1041 / 1.55 / 47.0% / 9.7% |

**8 种配置全部让净利下降。** 追踪止损把胜率从 50% 拉到 73%，净利却从 1962 腰斩到 1022。

原因：这个策略的利润由少数几笔跑满 2R 的单子承担。黄金在打到 2R 之前，
回撤经常超过 0.8R，任何追踪都会把这些本来会赢的单子提前砍在成本线附近。
**结论：该策略不适合追踪止损。功能保留但默认关闭。**

### 9.2 宏观结构过滤 —— 只是把利润从一年搬到另一年

新增 `macro_left/macro_right`：用更大窗口的分形（如 5/5、8/8）算一套宏观 swing，
局部结构放行后还要过大级别趋势这一关。起因是 2025 年最差的 5 笔里有 3 笔
是黄金单边上涨中的逆势空单。

| 窗口 | 2019 | 2020 | 2021 | 2024 | 2025 | 2026 | 合计 | 平均 PF |
|---|---|---|---|---|---|---|---|---|
| 关闭 | 61 | **379** | **439** | 471 | 60 | 123 | 1961 | **1.64** |
| 5/5 | 156 | 49 | 287 | 456 | **392** | 167 | 2013 | 1.52 |
| 8/8 | 45 | 84 | 119 | 324 | 187 | 158 | 1228 | 1.24 |

5/5 把 2025 从 +60 修到 +392，同时把 2020 从 +379 砍到 +49。**总收益几乎不变
（1961 vs 2013），平均 PF 反而从 1.64 降到 1.52。** 这不是改进，是重新分配。
**结论：默认关闭。**

## 十、跨品种验证 —— 这个策略只在黄金上成立

### 10.1 先修一个引擎 bug：币种换算

`guard.lots()` 里 USDJPY 的手数恒为 0，导致 15660 根 bar 上一笔交易都不开。
根因：引擎的盈亏公式 `(price-entry)×lots×contract` 得到的是**报价货币**金额，
而账户是 USD。USDJPY 的报价是 JPY，算出来的风险被放大了 158 倍，
全部被 `guard.lots()` 的最小手数保护拒绝。

修复：`EngineConfig` 新增 `quote_rate`（1 USD = 多少报价货币）与
`quote_rate_from_price`（USD/XXX 类品种直接用当根收盘价当汇率）。
手数计算用 `contract_size / quote_rate` 作为 USD 等效合约价值。

修复后黄金结果**逐分未变**（2821），USDJPY 从 0 笔变为 147 笔。

### 10.2 结构阈值改为 ATR 归一化

原来 `min_structure_points` 是硬编码 point 数（黄金 14000）。换到指数上
14000 点 = 140 个指数点，尺度完全错。现在改为 ATR 倍数：

| 系数 | 值 | 黄金上还原为 |
|---|---|---|
| `min_structure_points` | 1.63 × ATR(14) | 13990（原 14000） |
| `min_stop_points` | 0.93 × ATR(14) | 7982（原 8000） |
| `pullback_tol_points` | 0.05 × ATR(14) | 429（原 400） |

### 10.3 结果：除黄金外全部无效

资金 3000，风险 2%，各品种用自身点差与 ATR 归一化参数：

| 品种 | 起始 | 全期净利 | 笔数 | PF | 胜率 | 回撤 | 2024-2026 净利 | PF |
|---|---|---|---|---|---|---|---|---|
| **XAUUSDm** | 2017 | **+2821** | 124 | **1.52** | 45.2% | 15.2% | **+1105** | **1.55** |
| USDJPYm | 2017 | −179 | 147 | 0.96 | 34.0% | 24.6% | +342 | 1.14 |
| JP225m | 2021 | −33 | 63 | 0.85 | 31.8% | 2.7% | −5 | 0.97 |
| EURUSDm | 2021 | −631 | 64 | 0.71 | 26.6% | 24.7% | −97 | 0.87 |
| GBPUSDm | 2021 | −130 | 61 | 0.94 | 36.1% | 11.5% | −123 | 0.85 |

**除黄金外全部为负。** 此前"三品种组合把回撤从 32% 压到 15%"的结论无效——
非黄金品种本身不赚钱，分散化是假象。

机制解释：结构突破回踩是趋势跟随逻辑，需要标的本身有持续的 directional 行情。
黄金在 2017-2026 有长期单边趋势，外汇主要区间震荡，突破后回踩往往是假突破。

### 10.4 黄金 H1 vs H4

| 周期 | 根数 | 点差/ATR | 净利 | 笔数 | PF | 回撤 |
|---|---|---|---|---|---|---|
| H1 | 50000 | 3.3% | +544 | 383 | 1.04 | 25.8% |
| **H4** | 15579 | **1.9%** | **+2821** | 124 | **1.52** | 15.2% |

H1 的交易数是 H4 的 3 倍，但净利只有 1/5，PF 1.04 约等于没有 edge。
成本（点差占 ATR 3.3% vs 1.9%）吃掉了大部分利润。

## 十一、当前结论

**已具备**：一个通过 Gate 2 与样本外验证的策略，仅限 XAUUSDm H4。

| 指标 | 值 |
|---|---|
| 区间 | 2017-01 ~ 2026-10（9.75 年） |
| 初始资金 | 3000 USD |
| 总净利 | +2821（+94%） |
| 年化 | **约 7.0%**（复利口径） |
| 交易数 | 124（年均 12.7） |
| 胜率 | 45.2% |
| PF | 1.52 |
| 最大回撤 | 15.2% |
| 盈利年份 | 9/10 |
| 点差 600 压力测试 | +2636（仍盈利） |

**不具备**：
1. 收益量级不够——年化 7% 在 3000 美元账户上等于每年 210 美元
2. 交易频率太低——年均 12.7 笔，无法靠数量摊平运气
3. 无法分散——只有黄金有效，多品种/多周期都试过
4. 滑点、隔夜利息、部分成交未建模，实盘会更差
5. 尚未在 MT5 用真实 tick 数据复现（MQL5 版本未编译）

**下一步的正确方向不是继续调参**，而是增加**不同的策略逻辑**
（例如日内区间、事件驱动、跨周期共振），让多个低相关策略叠在同一品种上。
单一策略的收益天花板由「信号频率 × 单笔期望」决定，而这两项都已经到顶。
