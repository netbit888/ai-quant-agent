## 1. 设计目标与非目标

### 目标

1. **做单态一屏不滚**：空仓时能看到上一轮判断和等待锚点；持仓时能看到离止损/止盈/保本还差多少。
2. **决策可追溯**：每一轮 `act` 是为的什么、有没有被程序建议否决（`would_veto`），一眼可见，不用翻流水表。
3. **配置与监控物理隔离**：参数改动只在设置舱发生，做单台只显示「生效值」，不提供可误触的入口。

### 非目标（明确不做）

- 不做多主题换肤。现有 token 体系（`--bg/--panel/--fs-1..10/--sp1..6`）保留，只增不改。
- 不引入图表库。现有 SVG 手绘图表 + `preserveAspectRatio="none"` 的约束继续有效。
- 不做移动端适配。面板是 1280×800 起的桌面窗口。
- **不碰设计红线**：涨跌配色仍为**绿涨红跌**（用户指定，与 A 股相反，见 `--up: #2ecc71` / `--down: #ff4d4f`）。

## 2. 三态架构

现有 4 个 tab（实盘复盘 / 实时迭代 / 策略评估 / 策略库）保留不动，**在 `view-live` 内部再分三态**。

```
view-live
├── 态 A：做单台（默认）──── 决策 + 持仓 + 闸门 + 决策流       ← 本规范重做范围
├── 态 B：复盘台 ──────────── 战绩 / 分方向 / 教训库 / 本场复盘   ← 现有卡片重组，内容不动
└── 态 C：设置舱 ──────────── 品种 / 模式 / 模型 / 经验库 / 参数   ← 从卡片里抽出来
```

### 态切换规则

| 触发 | 行为 |
|---|---|
| 面板启动 | 进 A 态 |
| AI 线程停止 | 停在当前态，不强制跳转 |
| 用户点 tab | 手动切换，本会话内记忆 |
| 异常（API 失败连续 ≥3 次 / 止损快查失效） | 顶部状态带转红，**不自动跳态**（跳态会打断正在看的数字） |

**设计理由**：自动跳态在做单场景是反模式——用户正盯着持仓，页面自己跳走会丢上下文。异常用状态带颜色 + 一个可点的跳转按钮表达。

## 3. 做单台信息契约

一屏四区。字段全部取自现有 payload，无新增后端字段。

### 3.1 顶部状态带（sticky，高 44px）

| 位置 | 内容 | 字段 | 更新 |
|---|---|---|---|
| 左 1 | 运行指示灯 + 状态词 | `running` / `atBarState` | 15s |
| 左 2 | 品种 + 模式徽章 | `symbol` / `mode` | 15s |
| 左 3 | 持仓摘要「空仓 / 多 0.01 @4061.4」 | `pos` | 1s |
| 中 | 今日已实现盈亏 | `lvToday` | 15s |
| 右 | 急停按钮（唯一红色实心） | — | — |

### 3.2 决策环（左，占宽 62%）

这是 v2 的核心新增组件。把「本轮模型想了什么」从一行 KPI 副标题提升为独立区块。

| 元素 | 字段 | 呈现 |
|---|---|---|
| 动作 | `last_decision.act` | 大字：**做多 / 做空 / 不做** |
| 信号强度 | `last_decision.p_up` | 双向条，中轴 0.50，刻线在 ±0.06（开仓阈值），另标 ±0.06→±0.20 的强信号区 |
| 原因 | `last_decision.reason` | 正文，最多 3 行，超出折行 |
| 程序建议 | `last_decision.advice` / `advice_text` | 独立胶囊。`advice` 非空时显示，附「程序建议否决 / 已采纳」 |
| 否决留痕 | `last_decision.would_veto` | 存在时决策环左边缘转蓝条 + 右上角蓝标签「模型否决建议」 |
| 等待锚点 | `wait_step.{level,ts,side}` | 空仓时显示「等回踩至 4049.90 · 已锁 4 分钟」；drift 时显示「已漂移，重新观察」 |
| 本轮时刻 | `last_decision.ts` | 右下角小字，相对时间（「12 秒前」）+ 绝对时间 title |

**为什么 p_up 用条不用数字**：开仓条件是 `|p_up−0.50| ≥ 0.06`。数字 `0.62` 需要心算减 0.5 再判断是否过线，条形把阈值直接画出来。记忆里踩过 `p_up=0.0` 被照抄 46% 样本的坑，条形在 0.00 时会明显贴死中轴，异常比数字更刺眼。

### 3.3 持仓与闸门（右，占宽 38%）

| 元素 | 字段 | 呈现 |
|---|---|---|
| 持仓方向 + 手数 | `pos.side` / `pos.volume` | 大号 + 绿/红着色 |
| 开仓价 / 现价 | `pos.entry` / `tick` | 双列等宽 |
| **浮盈刻度尺** | `pos.peak_pnl` / `pos.pnl` | 水平刻度：0 → 止盈线，两条刻线（保本触发 `be_trigger`、止盈门槛 `tp_min`），峰值以浅色标记保留 |
| 保本状态 | `pos.be_arm_ts` | 三态徽章：未触发（灰）/ 已挂券商（绿）/ 挂失败已本地兜底（黄） |
| 离场倒计时 | `pos.open_ts` + `max_hold` | 「还剩 47 分钟」，`plan=trend` 时用 `max_hold_trend` |
| plan 标签 | `pos.plan` | 「趋势单」/「震荡单」，同时说明当前生效的 tp/hold 是哪一套 |
| 闸门触发态 | 6 个 gate | 常态灰显示名称，参数移入 fold；**触发时整格转色并置顶** |

**关键改动：闸门从「参数胶囊」改为「触发指示灯」**。
现状 6 个胶囊常驻显示 `−3.00 / 每 5 秒 / 3.25 / 3.25 / 3 分钟 / 60 分钟`——做单时这 6 个数字一辈子不会变，看了等于没看。v2 只回答一个问题：**现在有没有哪条闸门在逼近或已触发**。
- 未触发：灰色小字，仅名称。
- 逼近（浮亏 ≥ 止损线 70% / 浮盈 ≥ 止盈线 90% / 持仓 ≥ 上限 80%）：转黄。
- 触发：转红/绿实心，并在顶部状态带同步一条。

### 3.4 决策流（底部，横跨全宽）

替换现有 11 列表格。

| 现状列 | v2 处理 |
|---|---|
| 时间 / 动作 / 方向 / p_up / 盈亏 / 来源 / 开仓理由 / 平仓理由 / （详情按钮） | 压缩为：时刻 · 动作徽章 · 方向 · p_up 微条 · 盈亏 · 一句话理由（hover 展开全文） |
| 跳过 / 继续持有行 | 压成 4px 高灰条，行内无数值；鼠标 hover 才浮出摘要 |
| 复盘行 | 左侧加青色竖条，标注「复盘」 |

默认显示最近 **8 条真正执行过的行**（开仓/平仓/复盘）。跳过行以灰条带显示「另有 37 次跳过」，点开才展开。

## 4. 状态矩阵

做单台必须覆盖的 6 种组合，每种的视觉主次不同：

| # | 状态 | 主视觉焦点 | 次要 | 注意 |
|---|---|---|---|---|
| 1 | 未启动 | 启动入口 | 上次战绩 | 决策环显示空态，不显示陈旧数据 |
| 2 | 运行 · 空仓 · 无锚点 | 决策环 | 决策流 | — |
| 3 | 运行 · 空仓 · 等待回踩 | **等待锚点条**（横贯决策环底部） | 决策环 | 锚点漂移时要显式说「已漂移」 |
| 4 | 运行 · 持仓 · 未到止盈 | 浮盈刻度尺 | 闸门灯 | 保本未 arm 时尺上刻线为虚线 |
| 5 | 运行 · 持仓 · 保本已挂 | 保本徽章转绿 | 刻度尺 | 说明「最差平开仓价」 |
| 6 | 异常（API 连败 / 快查失效） | 顶部状态带转红 + 原因 | 决策环转灰 | 不自动跳态 |

## 5. 视觉规范

### 5.1 沿用（不改）

全部现有 CSS 变量：`--bg --bg2 --panel --panel2 --border --border-hi --text --muted --dim --up --down --good --bad --warn --info --info-lit --bad-lit --good-lit --gold-lit --accent --mono --sp1..6 --fs-1..10`。

### 5.2 新增

| 变量 | 值 | 用途 |
|---|---|---|
| `--ring` | `#0c1219` | 决策环底（比 `--panel` 深一档，让环成为视觉锚） |
| `--ring-hi` | `#16202c` | 决策环描边 |
| `--veto` | `#4a9eff`（复用 `--info`） | 否决留痕蓝条 |

### 5.3 硬规则（沿用项目既有约束）

1. 数字一律 `tabular-nums`，不加光晕、hover 不位移。
2. 表格 `th,td { white-space: nowrap }`；长句列 `max-width + word-break`；文本列左对齐、数字列右对齐。
3. 图表 SVG 高度固定 156px + `preserveAspectRatio="none"`；大图 `viewBox` 必须等于实际 client 像素 1:1。
4. 中文 `letter-spacing ≤ 0.5px`。
5. 关掉的规则必须显示「关闭」（如 `tp_min=0`），不能显示一个不存在的阈值。
6. 所有数字必须来自实际 `cfg`，禁止写死在模板里。
7. 涨跌配色：**绿涨红跌**。

### 5.4 字号分工

| 层级 | token | 用途 |
|---|---|---|
| 决策动作 | `--fs-9` (24) | 「做多 / 做空 / 不做」 |
| 持仓浮盈 | `--fs-8` (22) | 当前盈亏 |
| 区块数字 | `--fs-7` (16) | 刻度尺端点、KPI |
| 正文 | `--fs-4` (13) | 理由文本 |
| 标签 | `--fs-1` (11) | 闸门名、表头 |

## 9. 与 2026-10-30 UI 审计的衔接

`docs/ui-audit-2026-10-30.html` 已完成 **token 层**收敛（裸 `font-size` 115→0、字号 17 档→10 档、裸 hex 56→39、不达 AA 文本 45→0），并锁定了五条禁令：

1. 不加浅色主题　2. 不引入 UI 框架（Tailwind/Ant）　3. 不做移动端/窄屏　4. 不为"现代感"加阴影渐变　5. 不用 `display:none` 隐藏滚动条

本规范是**结构层**改动（信息分区、组件形态、状态可见性），与其正交，五条禁令全部继承。新增的两个 token（`--ring` / `--ring-hi`）必须走同一套规则：

- 新增后 `tools/ui_lint.py` 必须通过，不得引入裸 hex。
- `--veto` 直接复用 `--info`，不新建颜色，避免又回到"56 个裸 hex"的状态。

落地后实测：裸 hex 50 处 / 39 种（预算 45），token 层无裸 `font-size` / `border-radius`。

## 10. 实现陷阱（原型 + 移植阶段实际踩到的）

| # | 陷阱 | 现象 | 正确做法 |
|---|---|---|---|
| 1 | 绝对定位子元素用百分比高度 | 直方图柱高度写成 `height:40%`，实际渲染成 3px 扁条 | 用像素值计算，在 JS 里 `height: Xpx` |
