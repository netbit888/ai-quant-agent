AI Quant Agent 绿色版
========================================

一、运行前提
----------------------------------------
1. 本机必须装好 MetaTrader 5 终端，并登录要用的账户。
   程序不内置 MT5，它通过 IPC 连接你**已经运行**的终端。
2. 建议先打开 MT5 终端，再启动本程序。

二、启动
----------------------------------------
双击 AIQuant.exe，会打开一个独立的应用窗口——不是浏览器，没有地址栏和标签页。

  安装版：装到 %LOCALAPPDATA%\Programs\AIQuant（安装时可以改路径），
          开始菜单和桌面各有一个快捷方式，卸载用安装目录里的 unins000.exe。
  绿色版：整个文件夹拷到任意可写目录，双击里面的 AIQuant.exe。

窗口依赖 Microsoft Edge WebView2 运行时（Win10 / Win11 绝大多数已自带）。
真缺了会弹提示：点「是」打开官方下载页，点「否」先用浏览器打开
（功能完全一样，只是多一个浏览器窗口）。

第一次启动会弹「配置模型 API」：
  · 选供应商（智谱 GLM 有免费档，国内直连不用代理）
  · 填 API key
  · 点「测试并保存」——它会真调一次模型验证，失败会回滚，不会留坏配置

填完存在 config/.env。以后想换，点面板模型条右边的「配置向导」。
不想用 AI、只看账本的话可以点「稍后设置」，面板照样能用。

三、退出（重要）
----------------------------------------
**用窗口右上角「退出程序」按钮，或直接点窗口的 X。**

点 X 时程序会先拦下来问你：没持仓直接退；有持仓给你两个选择
「先平仓再退出」/「强制退出」。

为什么要问：这套策略不挂止盈止损，仓位躺在券商那边没人看着就等于裸仓。
强制退出不会平仓，那些仓位会留在账户里。

**别用任务管理器结束进程**——那等于拔电源，来不及平仓，也不会留日志。

四、数据在哪（这是唯一副本，别删）
----------------------------------------
  data/live/accounts/<账户号>/    账本、成交、教训库、AI 做单日志
  data/logs/                      运行日志、崩溃日志
  config/.env                     模型配置（含 API key，别共享这个目录）

整个文件夹可以整体拷走/换机器，账本跟着走。
覆盖升级时只替换 AIQuant.exe 和 _internal/，**不要动 data/ 和 config/**。

五、注意事项
----------------------------------------
1. **不要解压到 C:\Program Files 这类只读目录**，程序要往自己旁边写数据。
   解压到桌面、D 盘、任意可写目录都行。放只读目录会在启动时报「目录不可写」。
2. 同一个账户**只能开一个面板**。重复双击只会再开一个只读看板窗口，
   不会起第二个服务进程（两个进程会互相覆盖状态、重复下单）。
   那个看板窗口的标题带「已有一份在运行」，里面的「退出程序」会提示你回主窗口。
3. Windows 可能弹 SmartScreen「已保护你的电脑」，点「更多信息」→「仍要运行」。
   本程序没有代码签名。
4. 端口 8765 被别的软件占用时会自动改用 8766~8772，控制台会打印实际端口。

六、关闭 AI 做单但保留面板
----------------------------------------
面板上「关闭并清仓」= 停 AI + 平掉仓位，面板本身继续跑（账本照记）。

七、出问题时
----------------------------------------
  · 打不开窗口：看 data/logs/fatal.log 和 data/logs/app.log
  · 提示 MT5 未连接：确认终端开着，并且工具栏「算法交易」按钮是亮的
  · 模型调用失败：点「配置向导」重新测试 key

八、免责（请读一遍）
----------------------------------------
本程序是技术研究工具，不构成投资建议。

它会在你的交易账户上**真实下单**。AI 交易员按 1~3 分钟的价差做超短线，
不保证盈利，可能亏掉全部本金。它不挂止盈止损——出场靠程序按浮亏主动
市价平仓，但程序没在跑的时候仓位没有任何保护。

用之前先在模拟账户上跑够样本，再用你真愿意亏掉的钱。

本程序按「原样」提供，不附带任何担保。因使用本程序产生的交易亏损由使用者自负。
