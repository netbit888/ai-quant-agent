# SeatOne

> 一个人的交易台。

它不是回测框架，也不是策略研究项目。打开面板、点「开始做单」，它就在你的 MT5 账户上
按 M1 做 **1~3 分钟的价差**，每一笔都留痕，收盘后一笔一笔摊开给你看。

一个品种：黄金（`XAUUSDm`，美分账户用 `XAUUSDc`）。最小 0.01 手。

**当前版本 1.5.13 · 990 个单测通过。**

---

## 一、一轮决策做什么

不是"给个方向"，是一条闭合的决策链：

1. **取数**：拉最近的 M1，模型只看其中 14 根；另算一条 MA28（28 根收盘均价）作背景。
2. **程序先算结构**：ER（净移动 ÷ 总行程）、收盘位置、连阳连阴、当前振幅的 ATR 倍数、
   当前这根 K 线的形状（收盘位置 + 上下影线占比）。这些**不给模型原始 K 线**，只给结论。
3. **模型判断**：返回 `{"act": bool, "p_up": 0~1, "agree": bool, "reason": "..."}`。
   `act=false` 是允许的，也是常见的——不做交易不是失败。
4. **程序给建议，不拦**：程序会算一份"我建议你怎么做"（`_entry_advice`），
   但 `act_guard` / `top_long_ban` 两个开关**默认关着**，模型说做就做。
   建议与模型相反时，开仓记录里留一个 `would_veto` 字段——拦与不拦谁对，靠这格数据事后算。
   仍然会挡的只有一道：`|p_up - 0.5| < 0.06` 视为信号太弱，不够付点差。
5. **下单**：市价单，`magic=20261022`。只有市价单，没有挂单。

> 为什么程序不拦：10-27 深夜两笔逆势空，M5 单边 +22.7，程序当时**背书**了这两笔，
> 双双 -7.51。硬拦两头不讨好，所以改成留痕不干预。

平仓后有两个冷却：同向重进 **180 秒**（实测同向 ≤60 秒重进 102 笔、均值 -0.50 USD，是最差的一桶），
反向 **60 秒**（只防连环单）。

## 二、三种行情，三套打法

程序按 ER 分桶，开仓那一刻锁定，持仓期间不换：

| 行情 | 判定 | 打法 |
|---|---|---|
| **震荡** | ER < 0.30 | 低买高卖：贴下沿做多、贴上沿做空，中间不动手。允许"等回踩到 X"的等待锚点 |
| **趋势** | ER > 0.50 | **顺势直接做，不等回踩**。唯一否决依据是当前这根 K 线的形状（插针顶不做） |
| **说不清** | 0.30 ~ 0.50 | 只做位置明显的单，其余不做 |

趋势市里等待锚点是**整体停用**的。这是实测结论：95 个"等回踩"点回放，挂限价触及后
47 笔均值 **-1.21**；同一批信号直接市价，85 点胜率 60%。回踩接的是刀。

（所以模型在提示词里写"挂单/等回踩"，在趋势市里不会被采纳——执行层物理上也只有市价单。）

## 三、三种运行模式

| 模式 | 谁下单 | 说明 |
|---|---|---|
| **真实做单**（默认） | 程序 | 点「开始做单」前有一次确认弹窗，这一段不能绕过 |
| **纸面演练** | 没人 | 照常决策、照常记账、照常出场，只是不发单。用来验证新参数 |
| **辅助** | **你** | AI 喊单，程序不碰账户：给出方向后等你 90 秒手动进场、120 秒手动离场，滑点超过 0.80 USD 就放弃，并弹窗提醒 |

辅助模式是给"想自己按鼠标、但需要有人在旁边盯"的用法。这三种模式共用同一套判断和出场规则，
纸面演练也跑保本止损的本地兜底——否则"纸面表现"和"真实表现"差的就是这条保护。

## 四、出场：程序说了算

模型管入场，出场由代码按硬规则执行，不看模型的脸色：

| 规则 | 参数 | 行为 |
|---|---|---|
| 硬止损 | 浮亏 3.00 USD | 直接市价平，不问模型 |
| **保本止损** | 趋势单峰值 ≥ 3.25 | 把券商端 SL 抬到开仓价。纸面单由程序在浮盈回 0 时平 |
| 止盈门槛 | 震荡 3.25 / 趋势 7.00 | 没到门槛，模型说平也不平（也不调模型，省 token） |
| 持仓上限 | 震荡 1 小时 / 趋势 3 小时 | 到点无条件平，盈亏都平 |
| 止损快查 | 5 秒（近门槛切 2 秒） | 只读一个 tick、只判止损，不动模型 |

**开仓不带 SL/TP**。裸仓是这套设计里最需要你知道的风险：程序没在跑的时候，
仓位在券商那边没有任何保护。所以点窗口的 X 会先问你：先平仓，还是留着。

止损快查存在的理由很具体：决策间隔 60 秒，而 M1 单根振幅中位 1.51 USD、P90 2.99。
只在每 60 秒检查一次，价格能在两次检查之间跑完整根 K 线——实测一笔 13:42:42 浮亏 -2.06、
13:43:42 以 -3.77 平掉，**超调 0.77，把 3.00 的止损放大了 26%**。

## 五、盘后：一场一场看

面板首屏就是「本场复盘」。切场口径：上一笔平仓到下一笔开仓间隔超过 **30 分钟**断一场。

| 内容 | 说明 |
|---|---|
| 五个数 | 笔数 / 持仓中位 / 最大单笔风险占余额 / 止损宽度 / 手动平仓占比 |
| 自动标记 | 报复单（亏损后 5 分钟内再入场）、手痒（持仓 <1 分钟）、宽止损（>本场中位数 2 倍）、超仓 |
| 一句话备注 | 每场一句话 + 3 个快捷标签，10 秒，可跳过 |
| 下一场规则 | 只给 1 条，从固定指标表里选，下一场自动检查遵守 / 违反 |

不打逐笔标签，因为打完很累、隔天就忘。报复/手痒/宽止损全部由时间戳和价格算出来，不问你；
真正有信息量的粒度是「这一场我在干什么」，一句话够。

**小样本护栏**：本场 < 5 笔只显示过程指标，不显示胜率和 PF——n=8 的胜率置信区间是 ±35 个百分点。
近期质量模块同理，每个窗口都给 Wilson 95% 区间，n < 20 直接标「样本不足，不可据此决策」。

### 交易评分

纯规则计算，同一份数据永远同一个分数（LLM 只做解释，不进分数）。

- **单笔 0-100**：结果 40 / 纪律 30 / 风险 20 / 时长 10。
- **账户 A~F**：期望、盈亏平衡边际、稳定性、风险、纪律、样本六个维度各自定级，**取最差项**，不做加权平均——「期望 0.3R」和「回撤 50%」不可交换。

基准只有一条：`需要胜率 = 1 / (1 + 盈亏比)`。盈亏比 0.75 就需要 57.1% 胜率。
这条线不需要外部数据，换手法也改不了。

## 六、教训库

每笔平仓后等 7 根 K 线复盘，模型自己给「主题 + 教训」，按重复次数分域注入下一轮提示词。

- **可安装的包**：`data/live/accounts/<login>/lesson_packs/`，面板上像选 EA 一样切换、导入、导出。换账户不丢经验。
- **分域**：进场教训只进进场提示词，出场教训只进出场提示词，跨端硬过滤。
- **按行情软匹配**：震荡里攒的教训优先在震荡里拿出来用，但不硬排除。
- 教训存在 `lessons.jsonl`，**不随「重置战绩」清空**。

## 七、装起来

| 形态 | 适合 | 说明 |
|---|---|---|
| **安装包** | 日常使用 | `AIQuant-Setup-<ver>.exe`（文件名沿用内部代号，安装向导里显示 SeatOne），默认装到 `%LOCALAPPDATA%\Programs\AIQuant`，桌面和开始菜单各一个快捷方式 |
| **绿色版** | 换机器 | 解压到任意**可写**目录，双击 `AIQuant.exe` |

**不要装到 `C:\Program Files`。** 程序要往自己旁边写账本（`data/`）和配置（`config/`），只读目录会在启动时直接报错。

**卸载保留 `data\` 和 `config\`。** 账本是唯一副本——MT5 历史有保留期、换服务器就丢。程序不替你删。

前提两件：

1. 本机装好 **MetaTrader 5** 并登录目标账户。程序通过 IPC 连**已经运行**的终端，不内置 MT5。
2. 窗口依赖 **WebView2 运行时**（Win10/11 大多自带）。缺了会提示，也可以退回浏览器模式，功能一样。

首次启动弹「配置模型 API」：选供应商（智谱 GLM 有免费档，国内直连）→ 填 key → 点「测试并保存」。
它会真调一次模型验证，失败回滚文件。不想用 AI 可以点「稍后设置」，只看账本照样能用。

**怎么关**：点窗口的 X。有持仓时会拦下来问：先平仓再退出，还是强制退出。
别用任务管理器结束进程——那等于拔电源，来不及平仓也不留日志。

## 八、面板

一页两面，上面是今天怎么打，下面是打完怎么看：

- **做单台**：品种、真实/纸面/辅助、决策间隔、开始/关闭并清仓、教训库、出场闸门、设置舱。
- **决策流**：每一轮模型看到了什么、给了什么、程序建议什么、为什么没做。带特征快照，出问题时先看这里。
- **复盘区**：本场复盘、交易评分、近期质量、滚动期望、账户曲线、逐日盈亏、分方向/平仓原因/品种/星期、最近平仓记录。

上次用的品种、模式、间隔会记住，下次打开自动填好——记住的是「下次填什么」，不是「现在按这个跑」，
点「开始做单」的确认弹窗一个字都没少。

**付费 API 一律先确认**：`GET /api/live` 永不调模型，只返回缓存；生成走 `POST /api/advice`
且 body 必须带 `{"confirm": true}`。每次都记一行到 `api_calls.jsonl`（时间、模型、token 用量）。

## 九、数据在哪

多账户按登录号自动归档，在 MT5 终端里切账户即可，本工具不存密码。

```
data/live/
  index.json                 账户索引
  profile.json               品种画像（全局）
  accounts/<login>/
    deals.jsonl              原始成交（带 login，按 ticket 去重）
    daily.json               逐日盈亏
    account_daily.json       每日余额快照
    quality_daily.json       每日滚动质量
    position_snapshots.jsonl 持仓期间 SL/TP 变动
    autotrade_log.jsonl      每条决策（open/close/skip/hold/review）+ 特征快照
    lessons.jsonl            教训
    lesson_packs/            可安装的经验包
    advice.json              最近一次 AI 复盘
    api_calls.jsonl          每次付费调用
```

每条成交都带 `login`。早期版本没有这个字段，切账户时新账户的成交会追加到旧账本上，
净额/胜率/回撤全错且事后无法自动拆分——这是踩过的坑，不是冗余。

归档账户可以软删除（移到 `_trash/`），没有真删除。

### 备份轮转

面板启动时自动给每个账户打一份当日快照，之后每 30 分钟检查一次（连着开几天不重启也不会漏）。
产物在 `data/backups/<login>/YYYY-MM-DD.zip`，另有 `_global/` 收索引、品种画像和经验包。
**保留最近 14 份**，更旧的自动淘汰；只认文件名日期，手工放进去的文件不会被误删。

按当前体积（主账户 2.5 MB → 压缩后约 340 KB），14 天总量约 6 MB。

```
python -m live.backup --status                 # 看有几份、最新是哪天
python -m live.backup --now                    # 立即备份一次
python -m live.backup --restore 2026-11-04 --login 277733809 --yes
```

恢复会**先把当前目录移到 `_trash/restore-<login>-<时间戳>/`** 再解压，不是直接覆盖。
不这么干的话，备份里没有的新文件会留下，造成"恢复了一半"的假象。

`config/` 不进备份——里面有 LLM API key，复制出去等于扩散密钥。备份只读源目录、
只写 `data/backups/`，失败不影响启动和做单。

## 十、它做不到什么

写在这里，免得你抱着错误预期用它。

1. **不保证盈利。** 227 笔反事实回放里，最好的一组（止损 3.0 / 止盈 3.25）仍是负期望，
   胜率 46.6%，离打平所需的 48.0% 差 1.4 个百分点。这套规则把亏损结构改好了，没有把它变成赚钱机器。
2. **成本是硬约束。** 实盘 XAUUSDm 固定 240 points，0.01 手约 0.24 USD/笔。
   这就是止盈门槛必须定在 3 USD 以上的原因——抓 1 USD 的波动，光过路费吃掉 23.5%。
3. **样本都在少数几段行情里。** 按行情分桶得出的结论只对那几段成立。
4. **没有挂单、没有 trailing、没有动态止盈。** 这些都试过或在回放里是负期望，不要再加回来。
5. **它不等同于你的判断。** 程序给建议、模型做决定、你承担结果。

## 十一、从源码跑

```bash
# 面板（源码态，默认浏览器打开；安装版是原生窗口）
.venv\Scripts\python.exe -m tools.dashboard
.venv\Scripts\python.exe -m tools.dashboard --native   # 强制原生窗口
.venv\Scripts\python.exe -m tools.dashboard --web      # 强制浏览器（永远可用的调试入口）

# 只读复盘（终端）
.venv\Scripts\python.exe aqa.py live
.venv\Scripts\python.exe aqa.py live --ai        # 生成 AI 复盘（会先要确认，会产生费用）
.venv\Scripts\python.exe aqa.py doctor           # 环境自检：MT5 进程、连接、账本、端口
.venv\Scripts\python.exe aqa.py accounts list    # 已归档账户

# 测试
.venv\Scripts\python.exe -m unittest discover -s tests
```

打包（onedir，无控制台）：

```bash
tools\build_installer.bat     # → dist\installer\AIQuant-Setup-*.exe（需先装 Inno Setup 6）
tools\build_portable.bat      # → dist\AIQuant\AIQuant.exe
```

调控制台版本：`set AQA_CONSOLE=1` 再打包。**改前端 HTML/CSS 必须重新打包**——模板在打包时被复制进 `_internal/`。

更新走应用内一键升级：启动时检查 Release，分片并发下载（4/8/16 段按链路实测切换），
全段齐 + 大小 + MZ + sha256 四项都对才落盘。增量包平时 9 MB 级。
